# Contributing

This repository is primarily a portfolio product. Suggestions and focused PRs are welcome.

## Ground rules

1. Keep V1 scope lean — no auth/DB unless discussed.
2. Do not commit secrets, personal CSVs, or large raw dumps.
3. Add/adjust tests when changing profiling rules or API contracts.
4. Run backend `pytest` and frontend `lint` / `typecheck` / `build` before opening a PR.
